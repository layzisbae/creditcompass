# CreditCompass

CreditCompass shows Texas high school students which AP, IB and dual-credit courses count at 46 colleges, toward their major, and how many semesters and dollars they'll save. Built for a DECA Innovation Plan by Layli Kasumova, Tomball High School.

Live site: https://layzisbae.github.io/creditcompass/

Credit policies change and students should confirm with each college.
